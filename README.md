# Compriva

**Grocery POS & Retail Management**: a web back office and counter POS, plus a Windows desktop
checkout app that keeps selling offline.

| Folder | Contents |
| ------ | -------- |
| `backend/` | Laravel 12 REST API |
| `frontend/` | Next.js web app and the desktop app's screens |
| `frontend/src-tauri/` | Tauri 2 desktop shell (Rust, SQLite, printing) |
| `docs/README.md` | Installation, how it works, deployment, troubleshooting |

Start here: **[docs/README.md](docs/README.md)**.
